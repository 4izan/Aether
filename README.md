# Aether — audio storefront concept

A standalone Next.js storefront concept for Aether One, a fictional wireless headphone. It features a headphone product render built in CSS, a track selector with synthesized browser audio previews and sound-reactive rings, material details, and a working sample shopping bag.

## Run locally

From this folder, run `npm install`, then `npm run dev`, and open `http://localhost:3000`.

## Editing the concept

- Change the sound studies in `data/tracks.ts`.
- Adjust the product and storefront layout in `app/page.tsx` and `components/HeadphoneVisual.tsx`.
- Update colors, layout, and motion in `app/globals.css`.
- The product, sound previews, bag, and checkout are concept interactions only. Audio is synthesized in the browser; there are no original audio files, ecommerce service, or payment processing connected.

The product specifications and price shown are illustrative concept content.
